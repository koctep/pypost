# Hotkeys

In the app, open **Help → Hotkeys** for the live list (platform-native key names).
Common shortcuts registered there:

## General

| Action | Shortcut |
| ------ | -------- |
| Quit Application | `Ctrl+Q` |
| Settings | `Ctrl+,` / `F12` |
| Environment Manager | `Ctrl+E` |

## Tabs

| Action | Shortcut |
| ------ | -------- |
| New Tab | `Ctrl+N` |
| Close Tab | `Ctrl+W` |
| Next Tab | `Ctrl+Tab` |
| Previous Tab | `Ctrl+Shift+Tab` |
| Switch to Tab 1-9 | `Alt+1` … `Alt+9` |

## Request Editor

| Action | Shortcut |
| ------ | -------- |
| Send Request | `F5` / `Ctrl+Enter` |
| Save Request | `Ctrl+S` |
| Save As Request | `Ctrl+Shift+S` |
| Focus URL Bar | `Ctrl+L` / `Alt+D` |
| Switch to Params | `Ctrl+P` |
| Switch to Headers | `Ctrl+H` |
| Switch to Body | `Ctrl+B` |
| Switch to Script | `Ctrl+T` |

## Other useful shortcuts

These work in the UI but are not always listed under **Help → Hotkeys**:

| Action | Shortcut |
| ------ | -------- |
| Focus response search | `Ctrl+F` |
| Copy selected history entry as cURL | `Cmd/Ctrl+C` (History list focused) |

On macOS, many `Ctrl` shortcuts use the standard platform modifier as shown by
**Help → Hotkeys**.
