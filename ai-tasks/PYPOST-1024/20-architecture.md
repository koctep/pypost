# PYPOST-1024: Architecture Design

## Documentation Architecture

1. **Settings Encryption Reference (`settings.md`)**:
   - Outlines encryption modes, key sources, KID, and step-by-step migration procedures.
   - Links to `environments.md#hidden-values-in-export-files` for export warning details.

2. **Scoped Hotkeys Hierarchy (`hotkeys.md`)**:
   - General (Global application shortcuts).
   - Tabs & Workspace.
   - Request Composer.
   - Context-sensitive (Body editor, Response pane, History sidebar).
   - Platform modifier mapping (macOS Command vs Ctrl).
